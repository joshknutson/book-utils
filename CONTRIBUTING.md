# Contributing

Thanks for your interest in contributing! A few quick guidelines to get started:

- **Run tests**: Ensure tests pass before proposing changes.
  ```bash
  ./book-utils/.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
  ./book-utils/.venv/Scripts/python.exe -m pytest -q
  ```
- **Style**: Follow existing project style; use black/flake8 if configured.
- **Commits & PRs**: Keep commits small and focused. Open a PR against `main` with a short description and testing notes.
- **Issue Tracker**: Reference the issue number in your PR if relevant.

If you're unsure about design or scope, open an issue first to discuss.

Thanks — maintainers
